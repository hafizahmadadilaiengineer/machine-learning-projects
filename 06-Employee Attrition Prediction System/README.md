# 🚀 Employee Attrition Prediction System

An end-to-end Machine Learning application that predicts Employee Attrition, explains predictions using Explainable AI, and recommends retention strategies for businesses.

---

## Project Goals

- Predict Employee Attrition
- Explain predictions
- Recommend business actions
- Interactive dashboard
- REST API
- Production-ready deployment

---

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- SHAP
